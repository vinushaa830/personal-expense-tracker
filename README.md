Personal Expense & Budget Tracker

A Python-based application for tracking personal expenses and managing monthly spending.

Features

* Add expenses
* View all expenses
* Calculate total spending
* Categorize expenses
* Delete expenses
* Set a monthly budget
* Check remaining budget
* Simple command-line interface

Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* Loops
* Conditional Statements

How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python3 main.py
```
